快速开始

后端一体化托管前端：Python 起一个进程，浏览器打开即用，离线可用。

pip install -r requirements.txt
python run.py              # 等价 python -m pivothub，监听 127.0.0.1:8000
http://127.0.0.1:8000/     # 首次进入弹合规声明；空库自动播种演示项目

python -m pytest tests -q  # 可选：273 用例（含真机链路部署集成测试）

自带 scripts/lab/ Docker 靶场可做端到端真机验证；提权规则 / 固化技法 / 命令模板都是 data/ 下的 JSON，加文件即出现在插件市场。
